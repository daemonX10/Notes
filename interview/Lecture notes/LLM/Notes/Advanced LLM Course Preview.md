# Advanced LLM Course — Preview

## Course Structure

| Module | Topics |
|--------|--------|
| **1. Foundations of LLM** | Transformer architecture, pre-training strategies, post-training strategies, recent alignment techniques |
| **2. Efficiency** | Parameter-efficient fine-tuning (PEFT) methods, model pruning, model distillation |
| **3. Augmentation & Reasoning** | RAG, LLM agents, reasoning models |
| **4. Alternative Paradigms** | State Space Models (SSMs), multimodal models |
| **5. Understanding LLMs** | Physics of language models, interpretability techniques, ethics & concerns |
